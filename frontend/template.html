Getting started

  1. Scan for editing opens Google sign-in if needed and is required before description edits.
  2. Sync metadata (free) adds public view, like, duration, and description data. It does not edit YouTube.
  3. Open Bulk Edit, add replacements, preview them, then type UPDATE only after reviewing.
  4. Backups are created before edits. Use Download & Archive for copies of content you own.

If a scan appears stuck, check the browser for Google sign-in. If no sign-in page opens after a few minutes, read the Activity log and restart the local app.

How to use this toolkit ↗

Start here

A guide to your toolkit.

From connecting your channel to reviewing your first update.

01 / Connect & scan

First-time setup needs Python dependencies and a Google Desktop OAuth file named client_secret.json beside the app. The README has the setup steps.

Click Scan for editing. If Google sign-in opens, choose the account that owns the channel. Wait for the scan to finish before editing.

02 / Choose your videos

Use All videos for the scanned channel. To edit only some, open Videos, tick the uploads you want, and click Bulk edit these. Check the selected count in Bulk Edit.

03 / Add replacements

Paste the old text into Text to find and the new text into Replace with. Use Update Instagram for usernames and profile links. More options contains protected text, case sensitivity, and advanced regex patterns.

04 / Preview & review

Click Preview changes. Review the before and after text, skipped videos, and daily update budget. A preview saves your replacement settings but does not change YouTube. Changing settings requires a new preview.

05 / Confirm & apply

Click Apply and type UPDATE. A backup is verified before writing. Follow the Activity log for results. When your daily budget runs out, scan and preview the remaining work after the reset.

06 / Backups & downloads

Description backups are saved locally in backups/. Restoring a description is currently manual; see the README. Download & Archive saves media to your computer. Choose a preset and preview the command before starting.

Two ways to read your channel

Scan for editing uses Google sign-in to load editable descriptions, including private videos. It is required for Apply. Sync metadata uses yt-dlp to collect statistics and descriptions without spending YouTube API quota after your channel is known. It cannot edit videos.

Need a hand?

Scanning seems stuck

Check your browser for a Google sign-in window. Complete sign-in using the channel owner's account. If nothing happens after a few minutes, check Activity on Overview. Restart the app if sign-in was closed or cancelled.

Apply is disabled or no matches were found

Read the message beside Apply. Run Scan for editing first, check the old text matches your descriptions, then preview. Correct any replacement errors. If the daily budget is used, wait for the reset shown on Overview.

A replacement was skipped

Check the reason in the preview. A description might exceed 5,000 characters, contain protected text, or have an unintended link change. Make a smaller replacement and preview again.

The page is offline or an old design is showing

Stop the previous Python server with Ctrl+C, start python web.py again, then hard-refresh the browser with Ctrl+F5.

Download & Archive

Pull video, audio, captions, thumbnails and metadata off YouTube with yt-dlp.

Only for content you own or have permission to download. This does not bypass DRM or copyright. Downloading other people's videos may breach YouTube's Terms of Service — that call is yours.
